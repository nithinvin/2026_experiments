MongoDB Lab: answers for all five question sets

Every question has its own block. Copy a block, paste it into mongosh, check the output against the expected result, then take a screenshot. The blocks are written to run in order from top to bottom.

1 · StartIn Ubuntu: docker start mongo, then mongosh
2 · PasteClick Copy on a block and right-click in the terminal to paste. Press Enter if needed.
3 · ScreenshotType cls to clear the screen first, then paste. Take the screenshot with Win + Shift + S.
4 · Word docPaste the query into Word, put the screenshot under it, and use the question ID as the heading.

Run each block once. Running insertMany again creates duplicate records, and running $inc again adds to the value again. If something goes wrong, use the red "Start this set again" box at the top of that set.

Quotes: Word turns " into curly quotes. If you copy a query back out of Word, mongosh will reject it. Always copy from this page.

Learn: each question has a short "Why" note. Read it before you run the block, then predict the output before you look at it.

Expected results assume the blocks were run once, in order, starting from an empty database. Your _id values (ObjectIds) will be different from anyone else's, which is normal.
